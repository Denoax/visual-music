# Visual Music

**[Play Visual Music →](https://denoax.github.io/visual-music/)**

A dance floor you can fly through. Raised LED waves, free steering and audio-synchronised lighting accompany the complete *Around the World (La La La La La)* recording.

Choose **Start** to begin. Move the pointer, drag one finger or use arrows/WASD to steer; hold the scene to accelerate. The menu provides Pause, Replay and Settings. Settings keeps the music playing. After the complete recording, the visual loop continues without replaying the song.

This repository contains the production website and credits. Development sources and review history are maintained separately. GitHub Pages serves `main` from `/`; `.nojekyll` preserves the exact build files. [Deployment file hashes and source revision](deployment.json) · [Credits and notices](CREDITS.md).
