# Repository showcase

The active header is visual-music-loop.gif with visual-music-loop-poster.webp for reduced motion. Both use the same990×352 canvas as the current portfolio/Kona profile banners. The profile receives identical bytes.

The GIF combines the actual reviewed desktop renderer footage at media58–64.5s with original DOM lettering in the existing Instrument Sans. It runs at original pace with a0.5s lap crossfade; it is an edited documentation banner, not an uninterrupted runtime recording or exact periodic simulation. The64-colour GIF conversion is lossy. No runtime, camera, audio or scene changes were made. File cadence is separate from browser/device performance.

Exact inputs, outputs and processing: [animated-banner-source.json](animated-banner-source.json). Reproduction: node tools/github-animated-banner.mjs --source=/path/to/original/desktop-full.webm. The original full recording stays in the local review ZIP. FFmpeg, compatible Chromium and the existing locked development dependencies are required.

The portfolio and [Kona Desktop](https://github.com/Denoax/konata-hyprland-dotfiles) READMEs informed the animated header, centered introduction, real gallery and practical documentation. Their artwork is not copied. The actual gallery stills remain lossless copies of the reviewed scene frames. Original font notice: [Instrument Sans OFL](../../public/licenses/Instrument-Sans-OFL.txt). No model-generated media.
